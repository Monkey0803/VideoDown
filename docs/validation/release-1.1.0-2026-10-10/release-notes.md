# 拾影 1.1.0（Keepsake）

- 中英双语：界面文案跟随系统语言；Android 13 及以上可在「我的 → 外观 → 语言」为应用单独选择简体中文或 English。
- 英文名定为 Keepsake，中文名仍是「拾影」。
- 新增合集解析（默认关闭，最多 20 条）、字幕下载与内嵌、私有保险箱与应用锁、链接清单导入导出与设置备份恢复。
- 播放器支持双击 ±10 秒、左滑亮度、右滑音量、长按临时 2× 倍速、同名字幕轨道开关，并新增音频睡眠定时器。
- 下载新增全局与单任务限速、完成后自动存入相册（默认关闭）、继续观看进度。
- 全应用弹窗统一为卡片式弹窗骨架；存储管理弹窗改版（可用空间为主数值、占用比例条、运行任务预算卡）。
- 修复：检查更新对话框的三个动作排成一行；任务页与已存页的搜索框圆角与解析页一致。

# Shiying 1.1.0 (Keepsake)

- Chinese and English: the interface follows the system language, and on Android 13 or newer you can pick one for the app in My settings → Language.
- The English name is now Keepsake; the Chinese name stays 拾影.
- New: collection/playlist parsing (off by default, up to 20 entries), subtitle download and embedding, a private vault with app lock, plus link-list import/export and settings backup/restore.
- Player: double-tap ±10 s, swipe for brightness or volume, press-and-hold for a temporary 2× speed, a subtitle track switch, and a sleep timer for audio.
- Downloads: a global and per-task speed limit, optional auto-save to the gallery (off by default), and resume-watching progress.
- Every dialog now uses the same card layout; the storage dialog was redesigned (free space first, usage bar, running-task budget card).
- Fixed: the three actions in the update dialog share one row; the search fields on Tasks and Library match the corner radius of the parse field.
