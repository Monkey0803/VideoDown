## 边界与限制

- 核心设备测试使用隔离的下载目录、历史和偏好；实际文件删除、队列引擎、HTTP 请求与 WebView 加载均真实执行。导航测试使用生产导航图并注入隔离历史/解析替身，不请求外部网站；生产存储入口仅检查界面和只读扫描，不点击清理。
- 本轮没有重新验证真实外部账号登录或各平台远程完整下载，没有物理设备锁屏/后台/系统强制终止测试，也没有在 Android 8/9 真机重复验证旧版存储权限。
- 空间预检查是当前可用空间的估算；未知大小和多个并发任务没有全局空间预留，不保证传输全程不会耗尽空间。后续磁盘失败仍有分类提示。
- 进程退出后仍使用已有暂停恢复机制，需要用户继续；不引入自动后台唤醒。
- Kotlin 与 Python 独立只读审查提出的阻断问题已修复并复审；安全边界包括白名单、路径检查、符号链接拒绝、共享维护锁和清理时重验。
- 当前目录没有 Git 元数据，未暂存、提交或推送。P1 修改以 `/tmp/videodown-p1-backup` 为比较基线，保留已有批量/搜索等工作。
