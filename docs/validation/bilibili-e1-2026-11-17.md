# 哔哩哔哩 E1：链接与投稿解析验证（2026-11-17）

## 结论

Phase F 的 E1 已完成：B 站链接会被识别成 `VideoPlatform.BILIBILI`，归一化成
`https://www.bilibili.com/video/BV…`（保留显式 `?p=N`），`b23.tv` 短链只在跳转到可信视频页时
才被展开；番剧、直播、课程、音频、空间/频道列表直接报告「不支持」，不交给引擎。
真实站点解析已跑通（引擎路径，非提交链接），结果按 BILIBILI 标注并带可下载的媒体请求。

**E2（DASH 下载）、E3（应用内登录态）、E4（字幕过滤与完整在线验收）仍未开始**；
「解析合集」的分 P 枚举只有代码路径与默认跳过的在线用例，本轮没有可用的多 P 链接，保持未验证。

## 实现范围

- `domain/model/VideoPlatform.kt`：新增 `BILIBILI("https://www.bilibili.com/")`；补齐
  `DouyinAuthor.profileUrl`（不构造 up 主空间地址）与 `DouyinVideo.videoWebUrl`。
- `data/remote/BilibiliLink.kt`（新增，纯 Kotlin）：
  - 只接受 `/video/BV…`（12 位、区分大小写）与 `/video/av…`（大小写归一成 `av`）；
  - 显式 `?p=N` 保留（`N<=1` 归一掉），分享文案里的 `spm_id_from` / `vd_source` 等参数丢弃；
  - `live.bilibili.com`、`space.bilibili.com`、`audio.bilibili.com` 以及番剧/课程/音频/空间、
    频道列表、缺 ID 的路径一律 `Unsupported`；
  - `trustedTarget(target)` 只对可信主机上的单个视频页返回链接，供短链展开复用。
- `data/remote/BilibiliShortLinkResolver.kt`（新增）：手动逐跳处理 3xx，只跟随跳到
  `bilibili.com` / `m.bilibili.com` / `b23.tv` 的主机，最终目标必须通过 `trustedTarget`；
  其它主机或非视频页直接返回 null（不把开放重定向当解析入口）。
- `data/remote/VideoLinkExtractor.kt`：识别上述主机（含 `live.` / `space.` / `audio.` 子域，
  让它们也能给出「不支持」而不是落进通用引擎）。
- `data/repository/MultiPlatformVideoRepository.kt`：新增 `parseBilibili`——先归一化（短链先展开），
  再交给随包引擎解析；结果统一重标为 `BILIBILI`，来源地址写回归一化页面，变体补上 B 站 Referer。
  合集枚举沿用既有的「解析合集」开关与 `EngineRequest.PLAYLIST_LIMIT = 20`。
- `core/ServiceLocator.kt`：注入 `resolveBilibiliShortLink`（使用应用共用的 OkHttp 客户端）。
- `core/ErrorResources.kt` + 中英文案：`bilibili:unsupported`、`bilibili:short_unresolved`、
  `bilibili:missing_engine` 三个可落库的 key。
- `presentation/Labels.kt` + `platform_bilibili`：平台名称「哔哩哔哩 / Bilibili」，
  平台筛选与分享文案自动出现该平台。

## 未覆盖边界

1. **多 P 合集没有真实链接验证**：本轮只有单 P 的公开链接；分 P 枚举依赖 yt-dlp 对
   `noplaylist=False` 的处理，随包引擎版本变化时需要在 `live_bilibili_playlist` 下复验。
2. **`b23.tv` 只用本地 302 服务验证**，没有真实短链的网络展开；短链服务若跳转到 B 站的
   `b23.tv` 中间页再跳，仍受 3 跳上限约束。
3. **番剧/直播/课程/音频/空间只按 URL 形态拒绝**：没有逐个真实页面验证；站方把内容放进
   `/video/BV…` 形式时仍会交给引擎，最终由引擎的能力与授权决定成败。
4. **没有登录态**（E3）：需要登录或高清晰度的内容本轮不覆盖；匿名解析失败会给出引擎的
   `AUTH`/`ACCESS` 分类，不提供应用内登录入口。
5. **下载与 DASH 合并（E2）未在 B 站上验证**：E1 只保证解析出的变体带媒体请求；
   实际下载、音视频分轨合并与校验属于 E2，本轮不声明完成。
6. **字幕（E4）**：引擎返回的字幕语言未做 B 站专项过滤（`danmaku` XML）。
7. 平板/折叠屏、API 26/28 未验证；首页粘贴真实 B 站链接的 UI 流程没有自动化用例。
