# B 站字幕过滤与在线验收（E4，2026-11-17）

## 结论

E4 已完成：字幕表只暴露**文本**字幕，B 站引擎返回的 `danmaku`（弹幕 XML）以及直播聊天、评论等
非文本轨在解析层就被过滤，界面与引擎都不会再看到它们。JVM、设备与默认跳过的 `live_bilibili`
在线验收都已补齐并留证。

## 实现范围

- `data/generic/GenericMetadataParser.kt`：新增 `textSubtitleLanguages(...)`，在
  `languages(...)` 之后过滤 `danmaku` / `live_chat` / `comments`（大小写不敏感），
  同时作用于 `subtitles` 与 `automatic_captions`。过滤在解析层完成，因此：
  - 结果页不会出现「同时保存字幕」里的弹幕项；
  - 引擎请求的 `subtitle_langs` / `auto_captions` 不会包含弹幕；
  - 已存在的记录不受影响（它们存的是当时选中的语言列表）。
- 文本字幕的下载与内嵌沿用 C2 的既有路径（引擎 `writesubtitles` + `FFmpegEmbedSubtitle`），
  本轮没有改动；B 站真实字幕的下载/内嵌仍未实测（见未覆盖边界）。

## 未覆盖边界

1. **B 站真实字幕的下载与内嵌未实测**：本轮只验证「暴露哪些语言」；真实字幕文件需要视频本身
   提供文本字幕（部分需要登录），且内嵌依赖 FFmpeg 后处理器，未构造在线用例。
2. **弹幕之外的未知非文本轨**：只过滤已知的 `danmaku` / `live_chat` / `comments`；站点将来新增
   其它非文本轨时不会自动识别。
3. **多 P 合集与真实 `b23.tv` 展开**仍缺真实链接验证（E1 遗留）。
4. 平板/折叠屏、API 26/28 未验证；在线用例每次运行都依赖调用方提供链接。
