# 体验收敛验证记录（2026-11-19）

## 结论

本轮实现上一轮 UX 复核中除 B 站入口外的全部条目：保险箱门禁、恢复死路、任务页筛选/清理、
结果页画质可见性、已存更多入口与排序、首页粘贴/网页入口/取消解析、多选工具条与选择圈、
播放器手势说明、冷启动空态、看图触控区、站点页自适应与撤销、文件去向与失败通知。

**验证边界：本轮没有连接真机或模拟器，设备用例未执行。** 因此本记录不能作为设备验收证据，
也不能把相关条目勾成“已完成”。已执行的是编译与 JVM 测试；设备上的系统认证弹窗、视觉观感、
触控与通知行为仍需按仓库标准补跑。

## 已执行

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew testDebugUnitTest
./gradlew compileDebugKotlin
./gradlew compileDebugAndroidTestKotlin
./gradlew assembleDebug
```

- `testDebugUnitTest`：**728 例通过**。新增：
  - `core/VaultAccessTest` 2 例：公开记录直接放行；私密记录只在本次进程解锁后可读；锁定后再次拒绝。
  - `presentation/home/HomeBatchDownloadTest.private duplicate does not leak into the home prompt`：
    私密重复记录不会在首页弹出重复提示，而是按新下载处理。
  - `presentation/history/HistoryBatchTest.clear completed only hides tasks and keeps the saved library records`：
    「清除已完成」只写 `taskArchived`，不删记录；私密完成项始终不进入任务页；撤销后恢复可见。
  - `HistoryBatchTest.recoverable filter covers paused and failed but not running`：
    「可继续」筛选只包含暂停与失败，不混入进行中/已完成。
- `compileDebugKotlin`、`compileDebugAndroidTestKotlin`：通过。
- `assembleDebug`：通过（`app/build/outputs/apk/debug/`）。
