# B 站 DASH 下载验证（E2，2026-11-17）

## 结论

E2 已完成：B 站的视频流与音频流在解析结果里被合成为**同一个画质选择**，由随包 yt-dlp / FFmpeg
合并成一个文件；合并结果在下载完成时按 I2 的规则校验视频轨、音频轨与尾部完整性，缺少任何一条
要求的轨道或文件被截断都会判失败。DRM 格式不会出现在画质列表里，直播、付费与权限越权仍不尝试。
使用一条真实公开视频完成了「解析 → 下载 → 合并 → 双轨校验」的在线验收。

## 实现范围

- **同一画质选择**：`GenericMetadataParser` 对 `acodec == "none"` 的 B 站 DASH 视频格式选择
  码率最高的音轨，生成 `MediaSourceType.SEPARATE` 的 `MediaDownload`，`formatSelector` 形如
  `100026+30280`；引擎按该选择下载两路并合并，`usesEngine` 保证任务走引擎而不是直链。
- **音轨单独保存**：DASH 音轨同时作为独立音频条目（`audioOnly`），可只保存音频。
- **合并结果校验**：下载完成调用 `validateDownloadedFile` → `MediaIntegrityPolicy`：任务要求
  视频 + 音轨时两条轨都必须存在，并检查声明时长 90% 处仍有样本（I2）。
- **拒绝范围**：解析层过滤 `has_drm`，整条只有 DRM 时解析失败；直播链接在 E1 的链接层就被拒绝；
  不注入会员 Cookie、不绕过付费、不尝试权限越权（登录态属于 E3）。
- 未改 `MediaKind` 与既有引擎接口：视频仍是 `VIDEO`，提取音轨沿用既有模型。

## 自动化证据

### JVM

- `./gradlew testDebugUnitTest --rerun-tasks`：**654 个用例通过**。
- 新增 `BilibiliDASHSelectionTest`（3 例）：
  1. 两条 DASH 视频格式都配上最佳音轨（`30280`），`formatSelector` 为 `视频+30280`、
     带 `audioUrl`、`usesEngine = true`；已合并的 MP4 格式不重复配音频；
  2. 独立音频条目保留且按码率排序；
  3. DRM 格式逐条过滤，整条只有 DRM 时解析被拒绝。

### 设备（Android 17 / API 37 模拟器 Pixel_10_Pro，arm64）

- `BilibiliDeviceTest`：**6 条通过、1 条按前提跳过**（多 P 合集需要 `live_bilibili_playlist`）。
- 其中 `liveBilibiliDownloadMergesVideoAndAudio` 使用真实公开视频（链接由
  `-Pandroid.testInstrumentationRunnerArguments.live_bilibili=<链接>` 在运行时传入，**不写入仓库**）：
  - 解析出画质列表，选择最低的「带独立音轨」画质（`formatSelector` 含 `+`）；
  - 通过 `DownloadEngine` + `EngineMediaDownloader` 真实下载，`validateFile` 指向
    `validateDownloadedFile`，因此 I2 的轨道/尾部校验在真实合并文件上执行；
  - 完成状态为 `COMPLETED`，并用 `MediaExtractor` 再确认成品同时含 `video/` 与 `audio/` 轨；
  - 用例耗时 **27.9 秒**（含解析、下载、合并与校验）。
- 结果 XML 归档在
  [device-api37/BilibiliDeviceTest.live-download.xml](bilibili-e2-2026-11-17/device-api37/BilibiliDeviceTest.live-download.xml)。

## 未覆盖边界

1. **需要登录或付费的画质**（大会员 1080P+、4K、HDR、杜比）未验证：匿名路径能拿到什么就列出什么，
   不做会员绕过；这类内容属于 E3 的登录态范围。
2. **真实付费内容、地区限制、版权受限视频**未构造，只保证不尝试任何绕过手段。
3. **多 P 合集**仍缺真实链接，E1 遗留的 `live_bilibili_playlist` 入口继续默认跳过。
4. 在线下载只跑了**一次**，不同网络/CDN 下的速度与合并失败率没有统计。
5. 合并容器固定 `mp4/mkv`（引擎默认），未验证 B 站特殊编码（如 AV1）在目标设备上的可播放性；
   文件结构校验通过不代表设备解码器支持。
6. 平板/折叠屏、API 26/28 未验证。
