# P2 功能与验收记录（2026-09-30）

范围：批量链接导入；独立音轨下载及本地视频音频提取；实际文件重命名、收藏、分类；单个与批量自定义目录导出。均在手机端完成。播放器倍速、后台播放及画中画属于后续功能。

## 要求与证据

| 要求 | 实现与验收证据 |
|---|---|
| 多链接去重、顺序解析、页面内多媒体、独立选择 | `VideoLinkExtractor.extractAll`、`BatchImportViewModel`、`BatchImportDialog`；BatchImportTest 的 7 项 JVM 测试；[4 项窄屏界面测试](p2-evidence/narrow-P2BatchImportDeviceTest.xml)，包含 50 项失败列表、画质选择和 Home 入口实际旋转。独立音轨也参与可选格式。 |
| 部分失败、停止与重试、重复确认 | BatchImportTest 验证仅重试未完成解析和失败入队项，保留成功媒体选择；重复项提交前重新检查，界面验证取消、跳过和明确再次下载。超过 50 个链接明确拒绝，不静默截断。 |
| 独立音轨下载 | GenericMetadataParser 只接受明确 audio-only、非 DRM 的有效格式；真实本地 HTTP DASH 页面经实际引擎解析并下载音轨，[音频引擎设备证据](p2-evidence/audio-engine.xml)验证只有音轨和有效时长。传输类型按 HTTP/HLS/DASH 实际格式处理；远端需真实网站提供音轨。 |
| 本地视频提取、原文件保留、任务控制 | EngineMediaDownloader 从已打开源 FD 校验并复制到独立 snapshot；AAC 优先复制采样，其他编码转 AAC。实际设备验证 AAC 采样 SHA-256 一致、Opus 转 AAC、无音轨失败、离线真实队列暂停和恢复、snapshot 清理、原文件保留。队列中的提取任务沿用重试、取消和重复确认。 |
| 音频播放、分享和导出 | [4 项音频 UI 测试](p2-evidence/audio-ui.xml)包含实际 ExoPlayer 解码播放/暂停、库内提取与重复提醒、无音轨任务提示、系统音频 chooser；[窄屏 3 项 UI 测试](p2-evidence/narrow-P2AudioUiDeviceTest.xml)。设备验证 MediaStore.Audio 的 Music 路径、audio/mp4 与复制字节；系统 SAF 另验证真实 M4A 副本。 |
| 实际重命名、收藏、分类与筛选 | DownloadLibraryMetadataRepository、LibraryScreen、LibraryActions；7 项 JVM 测试含旧长标题、符号链接拒绝、真实历史写入失败、重命名回滚和中断恢复。[3 项界面测试](p2-evidence/library-organization.xml)及[窄屏版本](p2-evidence/narrow-P2LibraryOrganizationDeviceTest.xml)验证持久收藏、真实改名、分类筛选、旋转和错误后重试。分类是库内标签。 |
| 自定义目录、授权持久化、单个/批量导出 | DocumentTreeExporter、FileExportViewModel、FileExportDialog 接入库内单项和多选入口；[系统目录授权](p2-evidence/export-picker.xml)及[320dp 系统选择器批量测试](p2-evidence/export-picker-bulk-narrow.xml)。后者一项测试同时导出视频与真实 AAC 文件，验证持久读写授权、偏好重读、M4A 字节一致且原文件保留，全程不采用 shell 授权。 |
| 不覆盖同名、部分重试、停止与恢复 | FileExportTest 3 项验证碰撞命名、部分失败继续及只重试失败项、停止后只选择未完成项；[6 项真实 Provider 测试](p2-evidence/file-export-provider.xml)验证副本字节、写入失败删除新目标、恢复日志、无效目录、旧 provider 不可访问、完成 IO 交接取消及并发事务。测试 fixture 权限使用 shell，只证明文件操作，不证明授权 UI。 |
| 安全持久化及旋转 | 重命名历史采用 temp + fsync + 同目录 rename，成功持久化后才发布内存状态。导出各项独立 journal，活跃事务不被恢复误删；界面旋转保留任务，进程重建提示中断并清理未完成副本。无法访问的旧目录保留恢复记录，不阻止新目录。 |

## 验证环境与边界

- Pixel_10_Pro arm64 Android 17、16 KiB 页大小模拟器；1280×2856，默认 density 480，窄屏测试 density 640（320dp），结束后恢复默认。
- 音频设备使用 APK 内置 Python、yt-dlp 和 FFmpeg；AAC/Opus 文件自行生成，DASH 使用真实本地 HTTP 服务。证明本机引擎和应用调用链，不代表所有远端网站或账号可用。
- 系统音频 chooser 实际打开，验证 ACTION_SEND、audio/mp4、FileProvider URI 和读取授权标志；不选择接收者或执行对外发送，未验证某个第三方应用接收结果。
- 系统 ExternalStorageProvider 对 `.m4a` 可能返回 `audio/mpeg`；应用创建文件时请求 `audio/mp4`。系统导出测试检查返回音频 MIME、M4A 后缀及完整源字节，MediaStore 音乐导出单独验证 audio/mp4。
- 提取阶段进程组取消测试在 Python phase 事件时取消并成功重跑；该事件在启动 FFmpeg 之前，不单独证明正在运行的 FFmpeg 子进程终止。另有真实 DownloadEngine 复制阶段暂停/恢复测试，使用测试 Repository 握手确保时序，未替换文件复制、校验或引擎执行。
- 日志恢复测试覆盖事务中断和异常路径，不宣称真实断电测试。整批 SAF 导出不承诺进程退出后自动继续。
- DRM、直播录制和整站采集不在本轮范围内。无独立音轨的页面可以先保存视频再提取；无声音的视频会显示“原视频没有音轨”。
