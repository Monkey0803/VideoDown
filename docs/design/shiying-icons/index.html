04 / DESIGN SPECIFICATION

细节有尺度，语义有边界。

精致来自一致的比例和留白。功能图标以辨识度为先，不把品牌装饰带入每一个操作。

统一规范

网格与线条24px 画布 / 2px 主描边 / 圆角端点与转角。密集的画质字形采用 1.7px 光学校正。
颜色与状态普通图标使用主题前景色；选中态使用品牌深橙 + 浅橙底。深色模式使用杏橙与深褐底。
操作与触达常规 24dp，紧凑位置 20dp，辅助位置 16dp。按钮触达区域至少 48dp，图标不等于点击区域。
主题兼容SVG 使用 currentColor，选中实心图标反白色通过 --icon-on-fill 配置。品牌图标保持固定配色。
