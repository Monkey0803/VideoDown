# 设计交付验证

日期：2026-09-30。使用本机 Chrome + Playwright 检查设计展示页，使用 Sharp 导出并校验 SVG；这不是 Android App 或真机运行验证。

## 素材

- 68 个 SVG XML 解析成功：58 枚应用内图标、三个品牌方案及分层/小尺寸品牌源文件。
- 58 枚应用内图标分别以 16、20、24、32px 渲染成功，共 232 次导出检查。
- 三个品牌方案均导出 48、108、192、512、1024px PNG；推荐方案额外导出圆形、圆角方形裁切及 432px 自适应分层 PNG。
- 推荐前景按 432px 分辨率检查 alpha 边界，主体包含抗锯齿边缘的最大半径为 31.9301 画布单位，小于 33 单位安全半径。
- 对品牌比较图、界面效果图和图标总览进行了视觉检查。所有 PNG 均为矢量源的导出或真实浏览器截图。

## 展示页

- 1440、768、375px 三种宽度的浅色、深色页面均无水平溢出。
- 三个品牌按钮切换主展示标志、裁切预览及方案名称；每次仅一个按钮处于选中状态。
- 16、20、24、32px 四个尺寸按钮正确调整全部 58 枚图标的实际显示尺寸。
- 浅深色切换正常；键盘 Enter 可以操作主题按钮；按钮提供焦点样式与 `aria-pressed` 状态。
- 品牌方案、应用效果、图标家族三个导航锚点正常。
- 图标下载交互实际返回 `parse.svg`；62 个非压缩包本地链接均可访问。
- 浏览器控制台错误为 0，HTTP 请求失败为 0。
- 本地 `file://` 打开验证通过，主题及尺寸切换无需服务器或联网。
- 压缩包单独通过内容校验与解压 CRC 检查，包含展示页及其所有相对链接目标。
