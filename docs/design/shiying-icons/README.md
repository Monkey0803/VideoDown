# 拾影 · 暖橙极简图标系统

设计稿 v1.0 · 2026-09-30。围绕「留住心动瞬间」，为视频发现、下载、音频保存与私人影像收藏建立统一图标语言。

本交付为设计素材与静态界面效果稿，尚未接入 Android App。没有修改 Kotlin、Android 资源或主题。

## 查看与下载

- 打开 `index.html` 即可离线浏览；无 CDN、外部字体或联网请求。
- 页面支持浅深色切换、三个品牌方案切换、16/20/24/32px 实际尺寸查看，以及单个 SVG 下载。
- `shiying-icon-kit.zip` 包含完整交付文件，解压后保留目录结构即可浏览。
- `previews/` 包含品牌比较、界面效果、浅深色完整展示页及手机宽度截图。
- `icon-manifest.json` 是机器可读语义清单；`icon-semantics.md` 是中文语义与使用位置对照。

## 品牌方案

| 方案 | 核心意象 | 用途 |
| --- | --- | --- |
| 拾影框 · 推荐 | 圆角影像框、播放三角、微弧底边 | 正式品牌图标与首页小标 |
| 折角影像 | 折角影像页包裹播放符号 | 同气质品牌备选 |
| 收纳影匣 | 影像卡片、收纳托盘、播放符号 | 更突出文件收藏的备选 |

品牌源文件位于 `brand/`。三个方案分别提供完整 SVG 与 48、108、192、512、1024px PNG。完整图标带圆角，用于设计预览；Android adaptive icon 应使用独立前景与背景，由系统负责裁切。

推荐方案额外提供：

- `frame-foreground.svg`：108×108 透明画布的奶白主体。
- `adaptive-background.svg`：108×108 无圆角的完整渐变背景。
- `frame-adaptive-composite.svg`：无预裁切圆角的合成校验稿。
- `frame-monochrome.svg`：独立透明底白色主体；用于 Android 主题图标 alpha mask，不依赖彩色前景的颜色。
- 上述前景、背景、单色素材的 432px PNG，供后续 Android 资源转换。
- `brand-mark-small.svg`：24×24 单色光学校正版，用于首页品牌位置；跟随主题着色。

主标志使用 5.5 单位圆角描边；主体（含描边）位于以 (54,54) 为中心、直径 66 的安全圆内。圆形、圆角方形预览不能替代后续真实 Launcher 安装验证。渐变为左上杏橙至右下暖橙，不使用模糊、位图纹理或嵌入字体。

## 色彩规范

| 颜色 | 值 | 使用方式 |
| --- | --- | --- |
| 暖橙 | `#F2784B` | 品牌渐变、强调装饰 |
| 杏橙 | `#FFAD75` | 品牌渐变高光 |
| 奶白 | `#FFF8F5` | 品牌主体、浅色页面背景 |
| 深褐 | `#33251F` | 浅色主要文字及图标 |
| 深橙 | `#A34423` | 浅色模式的功能强调与小字 |
| 浅橙 | `#FFE6D7` | 浅色选中态背景 |
| 深色杏橙 | `#FFB18B` | 深色模式的强调图标及文字 |
| 深色橙褐 | `#553422` | 深色选中态背景 |

浅色主题避免将暖橙直接用于小字，改用深橙保证辨识度。成功使用绿色圆形勾选，警告使用橙色三角感叹号，失败使用红色圆形叉号；实际产品中始终保留文字说明，不能仅凭颜色表达状态。

## 应用内图标规范

- 共 58 枚，包含 4 枚导航基础形态、4 枚导航选中形态、3 枚通知图标以及功能、状态图标。
- 统一 24×24 网格、2px 主描边、圆角端点与连接；画质中的密集字形为 1.7px，已存图标中的小三角为 1.5px 光学校正。
- 常规 24dp，紧凑操作 20dp，辅助信息 16dp，突出操作 32dp。触达区域至少 48dp。
- 基础图标使用 `currentColor`，便于对应 Compose 的 `tint`。实心已存选中图标的内三角使用 `var(--icon-on-fill, #FFF8F5)`；后续转 Android VectorDrawable 时须解析为对应主题的反白色或使用透明镂空路径，不能直接导入 CSS 变量。
- 未选中导航为线性，选中态为深橙主体、浅橙胶囊背景与实心细节。胶囊由容器绘制，不写入 SVG。
- 已收藏为实心心形；播放为实心三角；暂停为双竖条。继续下载使用恢复环与向下箭头，禁止复用播放图标。
- 保存到相册为照片加号；导出文件夹为文件夹向外箭头。分类为标签，排序为不同长度列表与方向箭头。
- 通知图标使用透明底单色实心轮廓；导出通知 PNG 时须将 `currentColor` 解析成白色并保留 alpha，不能加入彩色背景。
- 动态配色下，功能图标分别绑定主题 `onSurface`、`onSurfaceVariant`、`primary`，选中容器绑定 `primaryContainer`；固定品牌配色不随壁纸变化。此为接入规范，当前没有修改 App 动态配色行为。
- `back`、`forward` 等方向图标在后续接入时按布局方向处理镜像；播放、下载、状态和媒体图标不镜像。

SVG 内 `<title>` 提供单独查看时的可访问名称。展示页里的装饰性图标使用 `aria-hidden` 并保留邻近文字；产品按钮接入时需提供操作标签与正确状态。

## 接入边界

本轮只交付设计。后续将 SVG 转为 Android vector、Compose ImageVector 或各密度 PNG 时，需要清除网页专用 CSS 变量并核对描边缩放、主题着色、可访问标签、自适应图标裁切及真实设备通知效果。不能将浏览器效果截图描述为 Android 运行验证。

## 验证

具体浏览器检查与素材校验结果见 `validation.md`。品牌和功能图标均为可编辑矢量绘制；PNG 为对应 SVG 的导出图，界面预览中的封面为抽象色块示意。
