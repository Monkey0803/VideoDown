# 功能排查与后续顺序（2026-10-09）

依据当前源码、已有验收记录和本轮真机结果整理。初始阶段只排查，后续按用户要求执行 P1；未重新执行所有历史设备测试。最新逐项结果见 `docs/validation/p1-remaining-2026-10-09.md`。

## 已具备的功能

平台及通用网址解析、网页辅助、批量导入、画质选择、重复提醒、下载队列与排序、暂停续传、分片合并、失败分类恢复、共享空间预留、残留清理、收藏分类和重命名、相册与文件夹导出、独立音轨及离线提取、播放续播与最高 4× 倍速、后台音频及画中画均已有实现。不要重新列为缺失功能。

并发空间管理本轮完成 199 项 JVM 检查及 4 项真机测试。真机四项限于本地媒体下载、合并取消、离线提取恢复和模拟空间不足监控，不能代替真实站点、后台下载服务、通知或完整播放界面的验收。

## 可选新增功能

这些不是现有需求遗漏，需先确认产品方向：

- 空间预算可视化：存储界面目前展示物理可用量和文件占用，可增加运行任务尚需空间以及不足原因，帮助用户理解为什么剩余容量仍不足。
- 下载自动继续：当前连接 Wi-Fi 后需要手动继续，进程恢复为暂停。可增加用户可关闭的自动恢复策略，区分用户主动暂停和网络/空间导致的暂停。
- 更新入口：引擎随 APK 固定更新。若希望无需手动查版本，可增加应用版本检查及更新说明；是否支持独立引擎更新需另行设计和验证。

## 不计入本轮待办

DRM 解密、直播录制、整站采集不在现有范围；ijkplayer 尚未接入，但当前已有 Media3 播放器，不能将未替换播放器直接视作缺失功能。
