# 拾影 · Android UI 设计说明

## 设计方向

以「留住每一帧」为核心概念。暖白背景降低长时间浏览的疲劳感，深海蓝承载品牌识别和沉浸式内容，珊瑚橙标记主要操作与下载状态。竖幅摄影封面突出视频内容。

## 页面与状态

| 页面 | 核心信息 | 主要操作 |
| --- | --- | --- |
| 解析首页 | 分享链接输入、最近保存 | 粘贴、解析、预览 |
| 解析结果 | 封面、作者、时长、画质 | 选择画质、保存 |
| 下载任务 | 进度、速度、已完成记录 | 暂停、续传、筛选、删除、预览 |
| 已存视频 | 本地视频封面与信息 | 浏览、预览 |
| 个人偏好 | 默认画质、下载和通知偏好 | 切换设置 |

## 基础视觉规范

- 品牌深蓝 `#172A45`，行动橙 `#FF794F`，暖白背景 `#F7F7F4`，完成绿 `#4AAF82`。
- 页面边距 22px；卡片圆角 16–25px；主要按钮高度 48–53px。
- 标题采用较大的字重和紧凑字距，辅助信息用低对比灰色，下载状态同时使用文字与颜色表达。
- 桌面提供流程总览，手机宽度下切换为全屏 Android 风格页面。

## 原型边界

这是用于评审视觉与交互的 HTML 原型。解析、下载、播放及偏好设置使用演示数据；当前 Android 项目实际支持抖音解析、画质选择、断点续传、历史记录和本地播放。原型中的「已存」与「个人偏好」页面属于设计扩展，尚未接入 Android 应用。
